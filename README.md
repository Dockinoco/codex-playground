# Artworks Gallery

静かな余白を活かした美術作品のコレクションビューです。検索、作者フィルタ、お気に入り、モーダルビューアを備えています。

## セットアップ

```bash
npm install
```

## 開発

```bash
npm run dev
```

## ビルド

```bash
npm run build
npm start
```

## 構成

- `app/page.js` : ギャラリー一覧・検索・お気に入り・ビューア
- `data/artworks.json` : 作品データ
- `public/artworks/` : 作品画像
